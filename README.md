# Two Lines to Your Past Self

Entry for the [make.fun](https://make.fun/r/41fw6r6c) bounty `u-suga-two-lines-to-your-past-self-f36c83ca`.

## Usage

Runs on Node 22.18+ (`program/v1`) and deterministically writes the two-line entry to `/output/entry.txt`:

```bash
node main.ts
```

Set `OUTPUT_DIR` to test writing to an alternate local directory.
